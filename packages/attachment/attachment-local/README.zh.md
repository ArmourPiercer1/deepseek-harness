# @deepseek-ai/dsh-attachment-local

[English](README.md) | 中文

这是 [`@deepseek-ai/dsh-attachment`](../attachment) 的私有本地实现。对象存放在 `<DSH_HOME>/attachments/v1/objects/<sha256-prefix>/<sha256>`，并通过不透明的 `sha256:` 标识符寻址。每个进程都会通过将每个祖先目录项逐级同步到文件系统根目录，为某个 home 一次性证明其持久性。随后，写入过程使用私有暂存目录、仅所有者可访问的文件、经过同步的临时文件、原子且排他的硬链接发布，并对发布路径执行目录同步（适用于 POSIX；Windows 依赖文件系统元数据日志），确保已报告的引用能够在崩溃后继续存在。

准入策略每条消息最多接受 20 张图片和 200MiB 的编码源字节。每个来源最多可使用 20MiB、64,000,000 像素，且每边不超过 8192px。随后，它准备一个与提供方无关的归一化附件。EXIF 方向会被应用，元数据和颜色配置文件会被移除，像素变为 8-bit sRGB/sRGBA，长边按 `normalizedImageMaxDimension` 等比缩小（默认 2048px）。归一化附件有独立的 `normalizedImageMaxBytes` 安全上限（默认 4MiB）。透明像素会被保留；Sharp/libvips 可能省略所有采样点均不透明的 alpha 平面。一个近邻有界采样器在不平均化高频像素的情况下对颜色复杂度进行分类。确认的低色彩图片先尝试 PNG（仅当输入无 alpha 通道时才使用调色板），然后依次尝试质量为 85、80、75 的 WebP。其他带 alpha 的图片尝试这些质量的 WebP；其他不透明图片尝试 JPEG。每个候选项仅在前一个候选项超出上限后才执行。只有当某一尺寸下的所有候选项都超出上限后，才会缩小尺寸。一个干净的、单帧的、8-bit sRGB/sRGBA 的 PNG、JPEG 或 WebP，若已同时满足两项归一化限制，则逐字节原样通过；16-bit PNG、GIF、动画输入、元数据、方向以及不兼容的颜色空间都会强制转换。源附件与转换后的附件各被完整解码一次。`saveImages` 在发布整个批次之前为每个归一化附件做一次准备和校验，因此校验失败不会留下部分引用，提交也不会重复完整的图片编码。

请求版本存放在 `<DSH_HOME>/attachments/v1/request-images/` 下。`readImageRequest` 在总像素预算下缩小已存储的归一化附件（不放大），然后执行独立的编码字节上限。请求编码器使用相同的颜色分支：低色彩图片先尝试 PNG（无 alpha 时才使用调色板），然后依次尝试质量 85 和 80 的 WebP；其他带 alpha 的图片依次尝试质量 85 和 80 的 WebP；其他不透明图片依次尝试质量 85 和 80 的 JPEG。它懒执行候选项，只有两次质量尝试都超出请求上限后才缩小尺寸。其缓存标识包含附件 id、transform 版本、像素与字节预算以及固定的编码器设置。缓存字节在使用前会被完整解码，并校验为 8-bit sRGB/sRGBA。同一标识的并发调用共享一次 transform 和一次缓存写入；取消其中一个等待者不会取消共享工作。调用方从单次读取组合出有序批次，而服务的 FIFO 限流器把 `imageCompressionConcurrency` 应用于并发的归一化与请求 transform。该设置范围是 1 到 8，默认 2；文件发布在准备完成后仍然保持有序。

`DSH_HOME` 按共享路径策略解析：显式配置、`$DSH_HOME`，最后是 `~/.dsh`。会话日志只包含引用和经过校验的元数据，绝不包含这个宿主路径。`readImage` 会把可选取消信号传入文件系统读取、在校验前后观察该信号，并保留取消语义，而不会将其包装成 `ATTACHMENT_READ_FAILED`。

## 模型体验

该包通过重启和 fork 后对历史用户图片与结构化模型图片输出的持久回放间接影响模型。

#### KV 缓存影响

归一化与请求投影都是确定性的。未变化的附件和路由策略会在后续回合复用完全相同的缓存请求字节。

## 已知限制与待完成工作

- 对象会无限期保留；基于引用的垃圾回收尚未实现。
- 本地后端假定宿主与提供方适配器共享同一个文件系统服务。
- 动态 GIF 来源仅保留第一帧；动画不在版本一的图片契约之内。
- 归一化编码器与请求编码器由所安装的 sharp/libvips 构建固定；编码器或 transform 版本升级会为未来的归一化附件或请求变体重新寻址，而既有对象保持有效。
