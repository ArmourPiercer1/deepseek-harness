# dsh-client-ui-team

[English](README.md) | 中文

DeepSeek Harness 团队插件的 Web 团队配置与状态呈现界面。

## 角色

团队插件的浏览器端 UI 插件。在设置面板中添加 Team 设置区块，展示 teammate 配置与使用说明；在会话流中注册内联团队标记 Chat 节点 —— 每条持久团队事件（`team/progress`、`team/control-request`、`team/control-decision`、`team/message`）一行紧凑单行；注册全局可见的「团队」会话视图标签页，数据来自只读的按 leader 键控团队镜像（`ctx.sessions.teams`；冻结团队性判定位于 runtime 的 `resolveTeamView`）；并为团队会话在输入框上方注册常驻团队坞条。

## 插槽注册

| 目标插槽 | 类别 | 内容 |
|---|---|---|
| `settings.section` | list/root | 包含 teammate 列表和设置说明的 Team 配置区块 |
| `conversation.chat.node` | keyed/session，key `team-marker` | 内联团队标记：每条持久团队事件一行紧凑单行，位于该事件自身的日志位置 —— 会话流可复现的团队账本 |
| `conversation.view` | list/session，id `team`，order 20 | 团队标签页：非团队会话显示一行零态文案；团队会话渲染完整四段正文 —— 委派时间线、成员组、任务板、事件流 |
| `conversation.input.dock` | list/session，id `team`，order 15 | 团队坞条：输入框上方常驻条（位于目标条 order 10 与队列条 order 20 之间）—— 折叠读数 `团队 · N 运行中 · M 待裁决`（零计数段省略）加可展开的紧凑成员状态行与任务行；仅团队会话渲染，跳转入口激活团队标签页 |

## 团队视图数据

标签页经其注册的 inject hooks 槽位读取 sessions 服务的团队镜像（`useTeamMirror`，按 leader 键控 `TeamView` 记录的只读选择钩子），并在标签页挂载且镜像缺席该会话时经 `ensureTeam`（单飞的 `team.projection` 一元调用）冷拉补齐。一个会话恰在它领导某个镜像视图、或任一镜像视图把它绑为成员（`members.sessionIds`）时才是团队会话；其余会话只渲染零态，不渲染任何其他结构。注册面还把现有会话打开通路以纯 `openSession` 回调形式传入，时间线条形条、成员行、事件流行与内联标记行点击切换即走它。坞条经其自身注册消费同一镜像源与 `ensureTeam` 回调，团队会话判定口径与标签页一致。

## 团队内联标记

会话流把每条持久团队事件渲染为一行紧凑单行标记 —— 整卡团队面板已废除。每个事件各占一行、位于该事件的日志位置，因此每次状态变化都新增一行：会话流即团队进度的可复现账本，逐事件刷屏是预期行为。四类事件各有其行，均含事件时间、类型标识与截断为一行的摘要（全文保留在行的 title 中）：任务进度（`team/progress` —— 任务主题加四态状态点）、审批请求（`team/control-request` —— 请求成员与工具、理由、等待裁决徽标；计划审批种类带独立标识）、审批裁决（`team/control-decision` —— 五档裁决值加可选理由）、成员间消息（`team/message` —— 发送方 → 接收方加内容）。请求行与裁决行在渲染层经各自的请求 id 配对，配对不跨行折叠，账本按事件逐条重放。点击行经行数据与权威镜像解析相关会话（成员行与审批配对即 id 到会话的连接 —— 不解析目录标签或委派参数）：目标即本行所在会话时，行在流内锚定自身（滚动居中）；目标是另一会话时先切换会话，流内锚定随之降级为切换本身 —— 目标会话中对应的行处于另一日志空间的 seq，此处无从命名。镜像无法为其请求 id 配对的裁决行渲染为惰性：禁用、绝不打开会话。

## 团队时间线

时间线段把 leader 视图的委派渲染为泳道：每个 teammate 一行（leader 不占行），泳道颜色按行索引在既有 `--dsw-alias-state-*` 令牌组成的固定色阶上循环，每个委派区间一根条形条，置于线性时间域上 —— 左端点取最早的委派开始或任务事件，右端点取最后结算时刻，有区间运行中时延伸到组件本地时钟。区间之间的空闲时间保持留白。滚轮在指针处缩放，左/右键拖拽平移，方向键 / `+` / `-` / `0` / `Escape` 覆盖键盘平移、缩放与复位。悬停条形条显示成员名、起止区间与时长；点击带已绑定会话的条形条把当前会话切换到该成员会话。无任何委派时，该段显示一行说明而不渲染泳道矩阵。

## 成员组

成员组段把 leader 视图的成员渲染为分组：首行固定为 leader 行（"回到 leader"入口，锚定视图顶层的 `leaderSessionId` —— 成员行缺席 leader 时同样渲染），其后每个非 leader 成员定义一个分组，按 `members` 序排列。分组容器行读作 `Name · N 活跃`，N 为运行中实例数；接口按多实例设计（共享 memberId 的行并入同一分组），本期至多一个。展开区列出该成员的实例行 —— 三态状态（已绑定/运行中/已结算，直接读取投影，不做二次推导）、最近工具调用（缺席时占位文案）、存在未配对 control-request 时的等待徽标。未绑定成员保留容器行并显示无实例说明。点击首行或实例行把当前会话切换到绑定的会话；当前会话所属的分组与实例行高亮。

## 任务板

任务板段渲染 leader 视图的任务列表：按首次出现顺序每任务一行，每行含状态点（待开始/进行中/已完成/受阻）、任务主题、状态文案、负责人（经成员行解析出成员名，D19，缺席时回退原始 id）与可选进度摘要。行直接读取投影的 `tasks`（每 taskId 取最新 `team/progress`），不做二次折叠。行不可交互；团队尚无任务进度时显示一行说明。

## 事件流

事件流段把审批链与成员间消息渲染为同一列表，按时间正序（旧→新）。审批行把每次 control-request 与其裁决配对：未配对显示等待态，已裁决显示五档裁决文案（单次允许/拒绝/升级给用户/批准计划/要求修订）与可选裁决理由；消息行显示发送方 → 接收方加内容，内容截断为一行（全文保留在行的 title 中）。默认渲染混合序最近 200 行；顶部"加载更早"按钮先从快照可表达流按 200 行步长追加更旧行（投影携带审批全史加最近 ≤500 条消息），该流加载完毕后 —— 经 sessions 团队面（`pageMessagesBefore`）分页拉取 host 的 `messagesBefore` 形态（锚点=已加载最旧消息三元，窗口按页长增长，"是否还有"取最新折叠观察到的 `messageCount` 推导）。分页失败保持响亮：带业务/传输消息的错误说明加带计数的余量说明，按钮保留可重试。点击行把当前会话切到该行会话：消息取记录会话，审批取请求成员的绑定会话（D9）；D16 的流内位置锚定在内联标记行（见「团队内联标记」），不在标签页的事件流上。

## 团队坞条

坞条把团队条注册到输入框上方的 input dock（order 15：位于目标条 10 与队列条 20 之间）。它仅在团队会话渲染 —— 与标签页同一冻结口径（镜像存在性，缺帧时经同一 `ensureTeam` 单飞冷拉补齐）—— 并读取同一 leader 键控视图。折叠单行读数携带 D23 全团队计数（`N` 运行中成员会话、`M` 未决 control-request；零计数段省略），箭头展开紧凑成员状态行（名 + 状态点，未绑定成员跳过）与任务行（主题 + 状态文案）。条的跳转入口激活当前会话的团队标签页；视图写入属 ui-conversation 私有，故在获得跨包视图切换契约之前，入口降级为对标签环团队按钮的 DOM 激活。

## 模型体验

无，因为该包是浏览器端 UI 插件，不注册任何面向模型的内容。

#### KV Cache 影响

无影响。

## 已知限制与暂缓事项

- MVP 阶段设置区块为只读；行内编辑 teammate 定义暂缓。
- 坞条的团队标签页跳转降级为对标签环团队按钮的 DOM 激活 —— 点击全页标签列表中首个文本与团队标签页一致的标签 —— 因为 chat store 的 view 动作属 ui-conversation 私有，且无正式的跨包视图切换契约；其他标签列表中同名的标签会抢先匹配，而未渲染任何标签环时（空白会话隐藏其头部）跳转静默无操作。
- 内联标记的跨会话点击降级为仅切换会话：目标会话中对应的行处于另一日志空间的 seq，在本行所在会话无从命名，故仅本行所在会话获得流内锚定。
- 镜像无法为其请求 id 配对的裁决标记渲染为惰性（禁用、不可点击）—— 例如首个快照帧到达之前 —— 点击不可用而非误指。
- 事件流的 wire 分页为标签页本地状态：新快照帧到达时已拉取的页被重置（加载深度保留、窗口按新帧重推导），已分页的更旧消息需重新分页 —— 保留的页与快照窗口的接缝否则会开口。
