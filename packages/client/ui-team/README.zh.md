# dsh-client-ui-team

[English](README.md) | 中文

DeepSeek Harness 团队插件的 Web 团队配置与状态呈现界面。

## 角色

团队插件的浏览器端 UI 插件。在设置面板中添加 Team 设置区块，展示 teammate 配置与使用说明；在领导者会话中注册一个持久的团队面板 Chat 节点：由 `team/progress` 事件折叠出的任务进度看板，加上来自 subagent 目录的 teammate 状态行；并注册全局可见的「团队」会话视图标签页，数据来自只读的按 leader 键控团队镜像（`ctx.sessions.teams`；冻结团队性判定位于 runtime 的 `resolveTeamView`）。

## 插槽注册

| 目标插槽 | 类别 | 内容 |
|---|---|---|
| `settings.section` | list/root | 包含 teammate 列表和设置说明的 Team 配置区块 |
| `conversation.chat.node` | keyed/session，key `team-panel` | 团队面板：任务进度看板与 teammate 状态行；当会话日志中出现 `team/progress` 事件或 `delegate_to_teammate` 工具调用后渲染 |
| `conversation.view` | list/session，id `team`，order 20 | 团队标签页：非团队会话显示一行零态文案；团队会话渲染完整四段正文 —— 委派时间线、成员组、任务板、事件流 |

## 团队视图数据

标签页经其注册的 inject hooks 槽位读取 sessions 服务的团队镜像（`useTeamMirror`，按 leader 键控 `TeamView` 记录的只读选择钩子），并在标签页挂载且镜像缺席该会话时经 `ensureTeam`（单飞的 `team.projection` 一元调用）冷拉补齐。一个会话恰在它领导某个镜像视图、或任一镜像视图把它绑为成员（`members.sessionIds`）时才是团队会话；其余会话只渲染零态，不渲染任何其他结构。注册面还把现有会话打开通路以纯 `openSession` 回调形式传入，时间线条形条、成员行与事件流行点击切换即走它。

## 团队时间线

时间线段把 leader 视图的委派渲染为泳道：每个 teammate 一行（leader 不占行），泳道颜色按行索引在既有 `--dsw-alias-state-*` 令牌组成的固定色阶上循环，每个委派区间一根条形条，置于线性时间域上 —— 左端点取最早的委派开始或任务事件，右端点取最后结算时刻，有区间运行中时延伸到组件本地时钟。区间之间的空闲时间保持留白。滚轮在指针处缩放，左/右键拖拽平移，方向键 / `+` / `-` / `0` / `Escape` 覆盖键盘平移、缩放与复位。悬停条形条显示成员名、起止区间与时长；点击带已绑定会话的条形条把当前会话切换到该成员会话。无任何委派时，该段显示一行说明而不渲染泳道矩阵。

## 成员组

成员组段把 leader 视图的成员渲染为分组：首行固定为 leader 行（"回到 leader"入口，锚定视图顶层的 `leaderSessionId` —— 成员行缺席 leader 时同样渲染），其后每个非 leader 成员定义一个分组，按 `members` 序排列。分组容器行读作 `Name · N 活跃`，N 为运行中实例数；接口按多实例设计（共享 memberId 的行并入同一分组），本期至多一个。展开区列出该成员的实例行 —— 三态状态（已绑定/运行中/已结算，直接读取投影，不做二次推导）、最近工具调用（缺席时占位文案）、存在未配对 control-request 时的等待徽标。未绑定成员保留容器行并显示无实例说明。点击首行或实例行把当前会话切换到绑定的会话；当前会话所属的分组与实例行高亮。

## 任务板

任务板段渲染 leader 视图的任务列表：按首次出现顺序每任务一行，每行含状态点（待开始/进行中/已完成/受阻）、任务主题、状态文案、负责人（经成员行解析出成员名，D19，缺席时回退原始 id）与可选进度摘要。行直接读取投影的 `tasks` —— 与聊天节点 `foldTeamBoard`（每 taskId 取最新 `team/progress`）同源同折叠 —— 不做二次折叠。行不可交互；团队尚无任务进度时显示一行说明。

## 事件流

事件流段把审批链与成员间消息渲染为同一列表，按时间正序（旧→新）。审批行把每次 control-request 与其裁决配对：未配对显示等待态，已裁决显示五档裁决文案（单次允许/拒绝/升级给用户/批准计划/要求修订）与可选裁决理由；消息行显示发送方 → 接收方加内容，内容截断为一行（全文保留在行的 title 中）。默认渲染混合序最近 200 行；顶部"加载更早"按钮先从快照可表达流按 200 行步长追加更旧行（投影携带审批全史加最近 ≤500 条消息），该流加载完毕后 —— 经 sessions 团队面（`pageMessagesBefore`）分页拉取 host 的 `messagesBefore` 形态（锚点=已加载最旧消息三元，窗口按页长增长，"是否还有"取最新折叠观察到的 `messageCount` 推导）。分页失败保持响亮：带业务/传输消息的错误说明加带计数的余量说明，按钮保留可重试。点击行把当前会话切到该行会话：消息取记录会话，审批取请求成员的绑定会话（D9）。D16 的流内位置锚定随 P5b 内联标记行落地；此前点击降级为仅切换会话。

## 队员状态语义

队员行是父会话中 `team:` 前缀标记的 continuable subagent 子会话。状态按行派生：子会话的 store 快照 activity 为 running 时显示运行中；已交接对应 inactive 且其名称出现在窗口内 `delegate_to_teammate` 目标中的队员；其余显示已绑定（已绑定基线，加载窗口内尚无委托）。目录 label 携带队员 name，而委托调用携带队员 id —— 二者是相互独立的 frontmatter 字段 —— 因此按 name 的关联是尽力而为的。

## 模型体验

无，因为该包是浏览器端 UI 插件，不注册任何面向模型的内容。

#### KV Cache 影响

无影响。

## 已知限制与暂缓事项

- MVP 阶段设置区块为只读；行内编辑 teammate 定义暂缓。
- 会话级团队状态 dock 栏与切换按钮推迟到后续工作。
- team/message 时间线（会话中按队员展开的消息行）暂缓；面板仅渲染进度看板与队员状态。
- 事件流的 wire 分页为标签页本地状态：新快照帧到达时已拉取的页被重置（加载深度保留、窗口按新帧重推导），已分页的更旧消息需重新分页 —— 保留的页与快照窗口的接缝否则会开口。
